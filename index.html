The AI Mentor is a full-stack serverless web application designed to demonstrate the integration of Large Language Models (LLMs) into real-time communication interfaces. It aims to solve the "empathy gap" in standard AI assistants by employing System Prompt Engineering to force the AI into supportive, multifaceted personas (Counselor, Medical Sage, Guardian).

HTML5/CSS3 Tailwind CSS Vanilla JavaScript Google Gemini API REST Architecture LocalStorage
CLIENT: UI Input Capture
VALIDATION: Local API Check
PRE-PROCESSING: System Prompts
NETWORK: Fetch Request
LLM ENGINE: Gemini 2.5 Inference
UI RENDER: DOM Updates
